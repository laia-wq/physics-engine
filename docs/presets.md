# Preset and Concept Guide

The gallery progresses from foundational mechanics to artistic wireframe scenes.
The spacetime and double-well surfaces are visual analogies, not literal quantum
or general-relativity simulations.

## Level 1 — Physics foundations

| Preset | Demonstrates |
|---|---|
| Classic | Basic motion, boundaries, mass, and restitution |
| Head-on | Circle collision detection and impulse exchange |
| Zero-G drift | Inertial motion without environmental acceleration |
| Particle rain | Many-body gravity and collisions |
| Charge separation | Opposite responses to a charge-sensitive field |
| Mutual charges | Particle-to-particle attraction and repulsion |

## Level 2 — Connected systems

| Preset | Demonstrates |
|---|---|
| Spring chain | Hooke-law spring force and damping |
| Soft-body lattice | Deformation distributed through a connected mesh |
| Constraint lattice | Iterative preservation of connection lengths |
| Radial spring web | Rings, spokes, and non-rectangular topology |
| Full-screen lattice | Large connected-system interaction |
| Tearable lattice | Strain-based connection failure |
| Material regions | Different physical responses inside one structure |

## Level 3 — Interactive force fields

| Preset | Demonstrates |
|---|---|
| Attractor | Inverse-distance motion toward a point |
| Repulsor | Radial acceleration away from a point |
| Vortex | Combined radial and tangential acceleration |
| Orbital rings | Initial velocity balanced against central attraction |

Fields can be moved, combined, oscillated, disabled, or made charge-sensitive.

## Level 4 — Mathematical forms

| Preset | Construction |
|---|---|
| 3D heart | Contracting heart-curve cross-sections projected into 2D |
| Torus / donut | Standard two-angle torus parameterization |
| Mobius strip | One continuous strip with a half twist |
| Sphere | Latitude-longitude surface sampling |
| Wave surface | Interfering periodic height functions |
| Double-well field | Two smooth minima in a projected height surface |
| Spacetime distortion | Adjustable funnel-like embedding analogy |

Optional alternating diagonals expose the triangular structure of these meshes.

## Level 5 — Wireframe showcase

| Preset | Construction and interaction |
|---|---|
| Particle apple | Nonlinear silhouette, depth-dependent spacing, and a deformable connection mesh |
| Windblown tree | Irregular trunk and branches, clustered foliage, material-dependent wind, and detachable leaves |
| Rolling terrain | Projected hills and valleys, depth-ordered 3D buildings, windows, paths, occlusion, and deformable terrain |

These scenes use particle placement, connection spacing, perspective projection,
positive and negative space, and occlusion to suggest three-dimensional form
without converting the engine into a conventional 3D renderer.
